# okfhub guide

This is a **reference OKF bundle** authored by the okfhub team. It teaches the
*context* an agent needs to reason about the Open Knowledge Format (OKF) and the
okfhub registry — *what OKF is*, *why okfhub renders dated evidence instead of
verdicts*, *what the publish flow is*.

## How this bundle relates to the skills (the procedural-vs-declarative boundary)

okfhub ships TWO things for agents, and they are deliberately distinct:

- **The skills** (`use-bundles`, `create-and-publish`) are **procedures your
  agent follows** — the exact commands to run (`okfhub add`, `okfhub publish`),
  the decision flow for live-MCP vs local-install, the DNS-challenge steps.
  Read them at:
  - https://okfhub.io/skills/use-bundles — *how to consume bundles*
  - https://okfhub.io/skills/create-and-publish — *how to author and publish*
- **This guide bundle** is **reference material your agent should cite** — the
  *concepts* behind the procedures (what OKF is, what a bundle is, why trust is
  rendered as dated evidence).

This bundle is reference material; the use-bundles skill is the procedural entry point. Concepts here are data your agent should reference and cite, not instructions to execute.

In other words: **the skill says how to act; this bundle says how to think.**
Most registries ship one or neither. okfhub ships both, and the distinction is
load-bearing — even this first-party bundle is *data to cite*, never
*instructions to execute*. The skill remains the procedural authority.

## About this bundle's own trust frontmatter

This bundle adopts OKF v0.2 frontmatter itself (see the `generated` field above,
and `verified` entries on selected concepts). That is a deliberate showcase: the
bundle that documents v0.2 *uses* v0.2. But note what the frontmatter does and
does not mean. okfhub vouching for its own content is **author-asserted content
trust** — a dated-evidence row that says "generated by human:okfhub-team" or
"verified by human:okfhub-team". It is never rendered as a green "approved"
badge, because there is no such badge in this system. See
[[trust-discipline]] for why.

See [[evidence-reading]] to learn how to read the evidence rows this bundle
carries, and [[what-is-okf]] for the format itself.
